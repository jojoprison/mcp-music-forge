# Формат карточки (конвенция `bugs/`)

Карточка = единица истории одного бага. Читают двое: **j** глазами в редакторе и агент грепом.
Один файл на домен, карточки внутри — по возрастанию номера.

## Шаблон

```markdown
## PROV-N — короткое название, читаемое без контекста
- **Статус:** open · 🟠 medium        ← либо: ✅ closed PR #12 · deploy 2026-09-01
- **Что:** симптом + корневая причина, 1–3 строки.
- **Где:** `providers/youtube/adapter.py:40-48` — живой указатель «иди смотри сейчас».
- **Простейший фикс:** KISS-путь с названным потолком.
- **Проверка:** чем доказывается, что починено (не «выглядит рабочим»).
- **Ключи:** `403` · `po-token` · `vSdVcQxebyE`   ← по чему грепать; пустые опускать
- **Связи:** [PROV-2] · `docs/research/<файл>.md`
- **История:**
  - `2026-08-28` обнаружен — замер N/M джобов
  - `2026-09-01` фикс PR #12 — permalink на код в состоянии фикса
```

Минимум для новой карточки: `Статус` + `Что` + `Где` + одна строка `История`.

## Ссылки, которые не протухнут

1. **Код в `История:` — permalink с 40-символьным SHA**, не `blob/main/…`: ветка уезжает при
   любой правке файла, и номера строк начинают показывать чужой код.
2. **Два вида ссылок на код, не путать:** `Где:` — `file.py:120` без SHA, живой указатель, дрейф
   это норма; `История:` — замороженный снимок с SHA.
3. **Даты — ISO `YYYY-MM-DD`.**
4. 🛑 **Ссылаться только на коммиченные артефакты:** PR / commit / `docs/**` / `.claude/rules/**`.
   Личная база знаний агента в git не лежит — ссылка на неё мертва для всех, кроме одной машины;
   называть нейтрально («база знаний агента»).
5. **Связанные карточки — в квадратных скобках** (`[PROV-2]`), чтобы греп находил обе стороны.

## Что карточка обязана содержать, а чаще всего не содержит

- **Замер, а не впечатление.** «Иногда падает» — не карточка. «53 succeeded / 4 failed, все
  провалы YouTube» — карточка.
- **Что проверено и НЕ является причиной.** Это дороже самой гипотезы: следующий заход не
  потратит день на уже отброшенное.
- **Ловушку замера, если она была.** Пример из PROV-1: `yt-dlp --simulate` читает только
  метаданные и проходит даже когда скачивание падает — стадии разные.
