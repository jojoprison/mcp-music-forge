## Домены и префиксы

| Префикс | Файл | Что покрывает |
|---|---|---|
| `PROV` | `bugs/providers.md` | скачивание: `providers/`, yt-dlp, YouTube, SoundCloud |
| `WRK` | `bugs/worker.md` | arq-воркер, очередь, транскод (`workers/`, `transcoder/`) |
| `API` | `bugs/api.md` | FastAPI и MCP-слой (`api/`, `mcp_music_forge/`) |
| `BOT` | `bugs/bot.md` | телеграм-бот `@yt_sc_mp3_downloader_bot` (`bot/`) |
| `INF` | [`bugs/infra.md`](bugs/infra.md) | docker, деплой, сервер `coco`, диск, бэкапы |

Файл домена заводится **вместе с первой его карточкой** — пустых заготовок не держим.
Каталог `incidents/` завести при первой прод-аварии (постмортем = что было, карточка = что делать).
