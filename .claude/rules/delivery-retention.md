# Досыл и чистка каталога джоб

## 🛑 Предикат «кому ещё должны файл» — ОДНА функция, а не два похожих условия

Чистка (`retention.sweep_old_jobs`) обязана спрашивать досыл вызовом
**`redelivery.pending_job_ids()`**. Не повторять его условие своими словами — ни целиком,
ни «только нужную часть».

**Что уже случилось (29.08.2026, PR #17 → #18).** Копия предиката потеряла третье слагаемое,
`job.status == failed`. Обычный успешный путь оставляет строку доставки с
`delivered_at IS NULL` навсегда — закрывать её на этом пути некому, — поэтому **каждая
успешная выдача бота добавляла каталог, который чистка не тронет никогда**. Со временем она
перестала бы чистить вовсе.

**Почему это не поймали проверки:** отказ тихий и в БЕЗОПАСНУЮ сторону (лишнее хранится,
ничего не теряется). Его пережили 60 тестов и мутант-килл 5/5 — мутанта «потеря условия
`failed`» убивать было нечем, потому что фикстуры сеяли удобную комбинацию
(`delivered_at` проставлен) вместо боевой (`succeeded` + открытая строка). Нашёл живой замер
на проде через минуту после деплоя.

**Механическая проверка, что источник правды общий:** мутант в `redelivery.py` (снять
`Job.status == JobStatus.failed.value` или `Delivery.attempts < MAX_ATTEMPTS`) обязан ронять
тест в `tests/test_retention.py`. Не роняет — значит копия вернулась.

## 🛑 Каталог джобы чистится ЦЕЛИКОМ, а не по половинам

`final/` читает досыл (`_audio_file`), `original/` отдаёт MCP-ресурс
`music-forge://jobs/{id}/original/{name}`. Обе половины доступны наружу, поэтому чистка одной
из них оставляет живые ссылки, отдающие 404.

🛑 Прежняя формулировка в карточке INF-1 («досыл берёт файл с диска» → не чистить `original/`)
называла **не ту половину** — не воспроизводить её в новых комментариях.

## Возраст берут из `job.updated_at`, а не из mtime каталога

mtime сдвигает любое чтение метаданных, и по нему каталог жил бы вечно. Файловая система —
арбитр только для каталога без строки в БД.

## Проверка боевого пути без удаления

Лог старта воркера (`Starting worker for 3 functions: … cron:cleanup_storage`) доказывает
только регистрацию. Чтобы проверить исполнение, ничего не удаляя, — задрать порог:

```
docker compose -f docker-compose.prod.yml exec -T -e JOBS_RETENTION_DAYS=99999 worker \
  python -c "import asyncio; from workers.tasks import cleanup_storage; asyncio.run(cleanup_storage(None))"
```
